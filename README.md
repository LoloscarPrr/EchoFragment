# EchoFragment

Narrative Action RPG 2D para Android.

## Visión
Viajar → descubrir evento → decidir → jugar la consecuencia → cambiar el mundo → continuar.

## Vertical slice
La primera meta es **Valle Gris**, una miniaventura completa con:
- exploración lateral 2D
- combate controlado en tiempo real
- espada, arco, báculo y dagas
- inventario y equipamiento
- atributos y decisiones contextuales
- estado persistente del mundo
- árbol inicial de habilidades
- múltiples resoluciones narrativas

## Tecnología
- Godot 4.x
- GDScript
- Android primero
- orientación horizontal
- pixel art detallado

## Repositorio independiente
Este proyecto no modifica WeekFlow, BookFlow, Binding of Ismael, Nexo de Runas ni ningún otro repositorio.
