# EchoFragment — Game Vision

## Género
Narrative Action RPG 2D side-scrolling.

## Pilar central
Las decisiones de una aventura narrativa deben poder convertirse en situaciones jugables reales.

## Loop
Viajar → descubrir evento → decidir → jugar la consecuencia → cambiar el estado del mundo → continuar.

## Protagonista
Un personaje base personalizable. El arquetipo inicial define equipo y ventajas iniciales, pero no bloquea la evolución futura.

Arquetipos iniciales previstos:
- Espadachín
- Arquero
- Mago
- Pícaro

## Familias de armas iniciales
- Espada
- Arco
- Báculo
- Dagas

## Atributos
- Fuerza
- Destreza
- Constitución
- Intelecto
- Voluntad
- Presencia

Los atributos no solo modifican números: también abren o cierran soluciones narrativas y jugables.

## Vertical slice
Valle Gris:
- ciudad
- camino/bosque
- ruinas
- fortaleza
- eventos con consecuencias
- inventario y equipo
- árbol inicial de habilidades
- enemigos básicos
- El Caballero Fragmentado
- múltiples resoluciones

## Primera plataforma
Android en horizontal.

## Motor
Godot 4.x + GDScript.
